# Fintech

Архивное состояние исследовательского торгового проекта перед разработкой новой архитектуры. Реализации текущей архитектуры сохранены в `src`, самостоятельные эксперименты и их результаты удалены.

## Содержимое

| Путь | Назначение |
| --- | --- |
| `src/Interfaces` | Контракты текущей архитектуры. |
| `src/Contracts` | Предсказатели, стратегии, assessor, источники данных MOEX и исполнители. |
| `src/Entities`, `src/ValueObjects` | Свечи, прогнозы, сигналы, действия и остальные структуры данных. |
| `src/Services`, `src/Factories`, `src/UseCases` | Портфель, виртуальный рынок, логирование, сборка зависимостей и сценарии обработки. |
| `src/config` | Настройки пары активов. |
| `src/capitalizationData.py` | Буферы диагностики, необходимые существующим assessor; сохранены для совместимости. |
| `tests` | Проверки времени доступности данных, обучения и исторического исполнения. |
| `AlphaForexTest.py`, `accauntStatus.py` | Сохранённые примеры работы с AlphaForex через MetaTrader5. |
| `silicon-metatrader5` | Сохранённая интеграция MetaTrader5; это отдельный вложенный Git-репозиторий. |

Публичные модули используют импорты относительно `src`, поэтому при собственном запуске нужно добавить его в PYTHONPATH. Тесты делают это самостоятельно.

## Проверки

Минимальные зависимости для тестов текущих причинных моделей:

```sh
python3 -m pip install -r requirements-causal.txt
python3 -m unittest discover -s tests -v
```

С существующим окружением проекта:

```sh
venv/bin/python -m unittest discover -s tests -v
```

`requirements.txt` сохраняет прежний набор основных зависимостей. Старым ML-моделям и интеграции MetaTrader5 могут потребоваться дополнительные зависимости из соответствующих реализаций и документации интеграции.

## Состояние проекта

Очистка не меняет устройство текущей архитектуры и не исправляет временные допущения старых стратегий. Новые причинные модели EWMAClosePredictor и RidgeClosePredictor, OpenCloseStrategy и CorridorAssessor находятся в `src`; исходные assessor и источник MOEX также сохранены.

Самостоятельных демосценариев с загрузкой биржевых данных и графиками в этом архивном состоянии нет. Новый сценарий будет реализован после проектирования и переноса архитектуры.

Сохранённые AlphaForex/MetaTrader5-примеры отправляют торговые запросы при запуске. Очистка их не изменяла и не запускала.
