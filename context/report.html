ARCH-08 No backtest/realtime separation — introduce IClock + IBacktestScenario 🟠 High ARCH 🟥 open ✨ new

Why now (Q-01 + Q-08): both backtest and realtime must work end-to-end on the same code; current MockContextProvider conflates real and elapsed time (see RUN-05).

Recommended shape:

  • IClock { now() -> int } · RealtimeClock uses time.time() · BacktestClock advances per candle.
  • IBacktestScenario { setup(); tick() -> bool; teardown() } owns clock + virtual IMarket with configurable slippage/fees.
  • Split factories: BacktestFactory vs LiveFactory; same Strategy/Assessor/Predictor.

Supersedes: ARCH-04 (the old vague "simulation vs production" finding).

DOM-09 Assessor lacks explicit IRiskPolicy 🟠 High DOM 🟥 open ✨ new

Why now (Q-03): user confirmed "risk-management однозначно должен быть в Assessor — он для этого и создавался". Current HalfInAssessor only does sizing (50% of cash); no max-position, max-drawdown, kill-switch.

Recommended shape: extract IRiskPolicy { maxPositionFraction, maxDrawdown, killSwitch(portfolio, ctx) -> bool }; pass into IAssessor.__init__. Even with RiskPolicy.unlimited() default, the port is needed for the diploma's architecture chapter.

IO-05 Preserve stats/ across runs (diploma artefact) 🟡 Medium IO 🟥 open ✨ new

Why now (Q-11): research results in stats/ are diploma evidence; main.py currently shutil.rmtrees them.

Recommended: on startup, rename logs/ → logs.YYYY-MM-DD-hh-mm/ and stats/ → stats.YYYY-MM-DD-hh-mm/ before recreating. Keep last N (e.g. 20), gzip older. Conceptually subsumes IO-03.

ML-07 Model persistence — explicit deferral 🟡 Medium ML 🟦 answered (deferred) ✨ new

Why now (Q-07): persistence is wanted but low-priority. Recording explicitly so it doesn't slip:

  • ITrainablePredictor.save(path) / .load(path)
  • joblib for sklearn/xgboost · keras.models.save_model for Keras
  • Critical: save RandomForestAlgo._initNormalization constants alongside the model — otherwise loaded model produces garbage.

Reopens automatically when ML-01 is scheduled.

RUN-05 MockContextProvider returns elapsed-time, not Unix timestamp — breaks scheduled triggers 🟠 High ⬇ was 🔴 RUN 🟦 answered

MockContextProvider.getContext() emits time.time() - self._startTimestamp (seconds since process start). HalfInAssessor schedules a sell at context.getTimestamp() + duration, then ScheduleTaskTrigger compares it against subsequent contexts — also elapsed time. Self-consistent but apples-to-oranges vs. anything using real Unix time (candles, MOEX data).

Impact: trading-correctness bug as soon as real timestamps enter the pipeline.

TRADE-01 No real broker integration — robot cannot actually trade 🟠 High ⬇ was 🔴 TRADE 🟦 answered

PortfolioSyncMarket only mutates the in-memory portfolio. QUIK/QuikPy.py and Examples/ exist but nothing in src/ wires them in. No QuikMarket / MoexMarket / TinkoffMarket implementation of IMarket.

Impact: product-level — project cannot fulfil its stated purpose of autonomous trading.

TRADE-03 No order-state-machine — only "execute then mark finished" 🟠 High ⬇ was 🔴 TRADE 🟦 answered

The BackgroundPollingExecutor calls market.execute(task); task.finish() with no notion of accepted, partially-filled, rejected, cancelled. The model has no concept of an order living between submission and fill.

Impact: robot cannot recover from broker errors or partial fills — a foundational gap for autonomous trading.

ARCH-01 No composition root for live trading — main.py only runs ML grid-search 🟠 High ARCH 🟦 answered

The MainFactory/DummyFactory hierarchy is fully wired but never instantiated. InfiniteActionUseCase / SingleActionUseCase are defined but never executed. main.py instead runs PredictorRetrainUseCase in a range(77, 101) loop. Two disjoint programs share the codebase: (a) ML R&D harness; (b) unfinished trading core. No actual robot entry point.

ARCH-02 Imports rely on a sys.path hack in main.py — no package metadata 🟠 High ARCH 🟥 open

main.py:10 does sys.path.insert(0, .../src) and every module then imports from Interfaces import …. There is no pyproject.toml / setup.cfg. Tests, sub-scripts, IDE debug sessions will break unless they replicate the hack.

ARCH-03 __eq__ implementations break IValueObject's polymorphic promise 🟠 High ARCH 🟥 open

IValueObject[T] suggests structural equality across implementations, but every concrete __eq__ uses isinstance(other, ConcreteClass). So a hypothetical second implementation of IAsset can never equal an Asset. Either the abstraction is wrong or the implementations are.

ARCH-04 No clear simulation/production separation — backtest disguised as production 🟠 High ARCH 🟪 superseded

MainFactory hardcodes MoexCurrencyDataSource (historic, bounded) + PortfolioSyncMarket (simulated) + MockContextProvider (returns constant price = 10). There is no path to swap one set for live components without writing a new factory.

ARCH-05 Factories is a poor-man's DI — no config-driven composition 🟠 High ARCH 🟥 open

MainFactory.__init__ is ~50 lines of hand-wired constructor calls; log filenames hardcoded; no env, no config file. Every variation (different predictor, asset, log dir) needs a new factory class. Two already exist (MainFactory, DummyFactory).

DOM-01 IContextProvider is too thin for real trading (no bid-ask / volume / orderbook) 🟠 High DOM 🟦 answered

IExecutionContext exposes only getPrice(assetPair) and getTimestamp(). No bid/ask, no spread, no depth, no broker-side balance. A robot can't size or time orders properly with this.

DOM-02 IStrategy has no access to portfolio or risk state 🟠 High DOM 🟦 answered

IStrategy.getSignal(prediction) -> ISignal sees only the prediction. Real strategies must consider current exposure, available cash, risk budget — none reachable here.

DOM-03 IAssessor overlaps responsibility with IStrategy 🟠 High DOM 🟦 answered

Strategy = prediction→signal. Assessor = signal→action. In HalfInAssessor the assessor does both sizing (how much) and direction (buy vs sell). The boundary is unclear.

DOM-04 IPredictor.getCandlesCount() conflates "input window" and "dataset item size" 🟠 High DOM 🟥 open

Used as input-window in PredictorTestingUseCase, but in ATrainablePredictor.addDatasetItem it must equal item.getCount() - 1. The +1 convention is implicit and undocumented.

ML-01 Trained models are not persisted 🟠 High ML 🟦 answered

Keras Sequential models live only in RAM and are rebuilt in __init__ on every run. No save/load anywhere. A long retrain run that crashes loses everything.

ML-02 Normalization constants are frozen after first training set + ZeroDivisionError risk 🟠 High ML 🟥 open

PercentageDeltaRNNPredictorAlgo._initNormalization runs once and freezes _maxOffsetAbs etc. _normalize divides by these — if any was 0 on a flat stretch, every later call crashes.

ML-03 PredictorRetrainUseCase retrains on the test set — look-ahead bias 🟠 High ML 🟥 open

PredictorRetrainUseCase.execute appends test candles to trainingCandleSeries mid-loop and retrains every 50 steps. The model is being trained on data whose labels it is then scored against. RMSPE numbers are not generalisation error.

ARCH-06 Contracts/ vs Services/ boundary not documented 🟡 Medium ARCH 🟥 open

Market/Portfolio/Logger live in Services/; DataSource/Predictor/Executor/Strategy/Assessor/ContextProvider in Contracts/. No documented criterion. Both depend on Interfaces, both contain decorators and stateful adapters.

ARCH-07 Heavy circular-import potential across sub-packages 🟡 Medium ARCH 🟥 open

Sub-packages import via top-level from Interfaces import … while Interfaces/__init__.py itself re-exports many things. Mitigated by from __future__ import annotations in ValueObjects, not consistently elsewhere.

DOM-05 Candle invariants duplicated across constructor and every with* method 🟡 Medium DOM 🟥 open

Candle duplicates ~10 checks across __init__ and seven with* methods. Should be a single _validate() helper.

DOM-06 Typo: Candle._vloume class annotation 🟡 Medium DOM 🟥 open

Candle._vloume: float — annotation typo, real attribute is _volume. Harmless but readers will pause.

DOM-07 Asset.__hash__ includes lotSize — same ticker, different lot ⇒ unequal 🟡 Medium DOM 🟥 open

hash((tickerCode, lotSize)) means two USD assets with lotSize 1 and 10 are different. Probably an accident; lot-size is broker metadata, not identity.

DOM-08 TurnBackAction._triggerTimestamp int/float lie 🟡 Medium DOM 🟥 open

Annotated int, populated with context.getTimestamp() + duration which (because of RUN-05) is a float. Same pattern repeated in many places.

ML-04 keras used directly, not tensorflow.keras — fragile 🟡 Medium ML 🟥 open

from keras.models import Sequential. Keras 3 standalone vs. tf.keras behave differently. Without version pin (RUN-03) the same code runs differently on different machines.

ML-05 RandomForestPredictor is misnamed — actually uses XGBoost on CUDA 🟡 Medium ML 🟥 open

RandomForestAlgo uses XGBRegressor(device="cuda"). Misleads readers; crashes on machines without CUDA.

TRADE-04 PortfolioSyncMarket models no fees / slippage / spread 🟡 Medium TRADE 🟥 open

Every execution at exact context.getPrice(...). PnL numbers will overstate reality.

TRADE-05 Short positions allowed silently in RuntimePortfolio.sellAsset 🟡 Medium TRADE 🟦 answered

Selling an asset never bought creates a negative position. For a safe robot, this should be an explicit, configurable feature, not an accident.

CONC-01 BackgroundPollingExecutor has no shutdown / error handling 🟡 Medium CONC 🟥 open

_polling is a while not done: ... time.sleep(0.5) loop with no stop signal, no try/except. If market.execute raises, the thread dies silently.

CONC-02 Cross-thread mutation of Portfolio without locks 🟡 Medium CONC 🟥 open

Executor runs in a worker thread; RuntimePortfolio._contents / _baseAmount are mutated with no Lock. Race-condition risk with multiple actions.

IO-01 FileLogger.log opens the file on every call 🟡 Medium IO 🟥 open

FileLogger.log performs open(...,'a') + write + close on every chunk. With InfiniteActionUseCase at high frequency this becomes a hotspot. Keep the handle open or buffer.

IO-04 No caching / retry / backoff for MOEX HTTP calls 🟡 Medium IO 🟥 open

MoexCurrencyDataSource._fetchMoex hits iss.moex.com synchronously, no retry, no caching, no rate-limit handling. Every grid-search iteration repays the full network cost.

TEST-01 Zero automated tests in the repository 🟡 Medium TEST 🟥 open

No tests/ directory, no pytest config, no test files. For a system handling money this is the single biggest risk multiplier. Start with pure VOs (Asset, AssetPair, Range, ExecutionContext, Candle), then Entities, then Strategy/Assessor.

TEST-02 No CI / linting / type-checking pipeline 🟡 Medium TEST 🟥 open

pyrightconfig.json exists but there is no GitHub Actions / GitLab CI / pre-commit. Pyright reports are not blocking. Add ruff + pyright + pytest in CI.

SEC-01 QUIK credentials / connection details handling unclear 🟡 Medium SEC 🟦 answered

src/configLocal.py is gitignored, but there is no example template, no env-var fallback, no documented secret strategy. New devs cannot bootstrap; secrets risk leaking via logs.

RUN-01 Contracts package fails to import — RandomForestPredictor/ has no __init__.py 🔴 Critical RUN 🟩 resolved

src/Contracts/Predictor/__init__.py:18 contains from .RandomForestPredictor.RandomForestPredictor import RandomForestPredictor, but src/Contracts/Predictor/RandomForestPredictor/ has no __init__.py. Importing the Contracts package — which main.py does at line 15 — will hit ModuleNotFoundError.

Impact: project may not start at all on a clean checkout (depends on Python's implicit-namespace-package fallback rules).

RUN-02 _id fields are typed str but store uuid.UUID (pervasive) 🔴 Critical RUN 🟩 resolved

Task, AAction, APrediction, ASignal, CandleSeries, PredictionMeta all declare _id: str but assign uuid.uuid4() (a UUID object). getId() -> str lies.

Impact: type-system lie; serialization, equality and pyright checks behave unexpectedly.

RUN-03 requirements.txt is dramatically incomplete & unpinned 🔴 Critical RUN 🟩 resolved

requirements.txt lists only pytz, pandas, requests, matplotlib, keras. Code also imports numpy, tensorflow, xgboost, scikit-learn, joblib, seaborn plus QuikPy / pyzmq stack. No versions pinned.

Impact: reproducibility broken; fresh clone cannot install.

RUN-04 RuntimePortfolio.getCapitalization breaks IPortfolio contract → TypeError 🔴 Critical RUN 🟩 resolved

IPortfolio.getCapitalization takes no args. RuntimePortfolio.getCapitalization requires context: IExecutionContext. LoggedPortfolio.getCapitalization calls self._portfolio.getCapitalization() with no arg → TypeError at call time.

Impact: Liskov violation; latent crash. Currently nobody calls the method — itself a smell (dead code).

TRADE-02 Fractional lots flow through Task & Portfolio — silently accepted 🔴 Critical TRADE 🟩 resolved

HalfInAssessor computes lotCount = volume / price / lotSize as a float. Task declares _lotCount: int but only checks < 0, so a fractional 0.83 survives. RuntimePortfolio.buyAsset multiplies it by lotSize and stores the result. On a real exchange that order would be rejected — the simulation already diverges from reality.

Impact: trading-correctness bug + type-system lie.

Folder works as an implicit namespace package by accident; brittle.
